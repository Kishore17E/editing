# KISHORE EDITS — Video Editor Portfolio

A high-converting, premium portfolio website for freelance video editor Kishore, specializing in short-form content, cinematic edits, motion graphics, and sound design.

## 🎬 Features
- **Hero Section**: Immediate cinematic showreel preview with quick CTAs.
- **Selected Work**: Interactive 6-project gallery featuring dynamic aspect ratios (vertical 9:16 reels, square 1:1, and cinematic 16:9).
- **Fullscreen Lightbox Player**: Native-ratio video player modal with smooth animations.
- **Services & Workflow**: Clean editorial breakdown of services (Short-Form, YouTube, Motion Graphics, Color & Sound) and the 4-step client process.
- **About & Advantage**: Professional bio and key reasons to collaborate.
- **Contact & Socials**: Connected directly to Instagram, LinkedIn, and Email.
- **Responsive & Lightweight**: Mobile-first design with smooth cursor interactions on desktop.

## 📁 Project Structure
```
kishore-edits/
├── index.html        # Semantic HTML5 structure
├── styles.css        # Minimalist dark cinematic styling & animations
├── script.js         # Lightbox modal, video loops, and interactions
└── assets/           # Video showreel, project clips, and portrait photo
```

## 🚀 Live Deployment
This site can be deployed instantly for free on:
- **GitHub Pages**: Go to Settings > Pages > Deploy from branch `main` / `root`.
- **Netlify**: Drag and drop this folder onto [app.netlify.com/drop](https://app.netlify.com/drop).
- **Vercel**: Import this GitHub repository on [vercel.com](https://vercel.com).
